# project-1

 * Text to speech Translator

The Text-to-Speech Translator is a web-based application that converts written text into speech and can also translate the text into multiple languages. It helps users listen to text in their preferred language, making communication and learning easier and more interactive
 

 * Features
  
- Multilingual Translation: Translate text into different languages using an API.
- Text-to-Speech Conversion: Converts translated text into natural-sounding speech.
- User-Friendly Interface: Simple and responsive design for easy use.
- Real-time Processing: Instant translation and speech generation.

 * Technologies Used

- HTML5
- CSS3
- JavaScript

 
 * How It Works

1 . User enters or pastes text in the input box.

2 . Selects the target language for translation.

3 . Clicks the “Translate” button to see the translated text into speech.
